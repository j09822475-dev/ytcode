# trendbot — инструкции для Claude

Проект — эксперимент по поиску трендов TikTok через браузер на компьютере пользователя
и созданию похожего контента. Сбор и статистика — код в `trendbot/`; анализ и идеи —
твоя работа по отчётам.

## Когда просят «найди тренды»

1. Если нет `trendbot.toml` — скопируй `trendbot.example.toml`, спроси нишу, ключевые
   слова и хэштеги.
2. Если в `data/browser-profile` нет входа — попроси пользователя выполнить
   `trendbot login` (вход делает человек, не ты).
3. Запусти `trendbot run` (долго: минуты). Если появилась капча — попроси пользователя
   пройти её в окне браузера. Не пытайся обходить капчи и защиту.
4. Открой последний `data/reports/*/report.md` и **посмотри кадры** из
   `data/reports/*/frames/*/` (Read по .png).
5. Напиши разбор в `data/reports/<та же папка>/analysis.md`:
   - 3–5 трендов (звук / формат / тема), для каждого: почему это работает, насколько
     он свежий (возраст роликов, прирост), подходит ли нише;
   - что общего у лучших роликов: хук в первые 1–2 секунды, текст на экране, длина,
     темп, лицо в кадре или нет, тип монтажа;
   - 5 идей роликов для канала: хук, сцены, текст на экране, звук, описание, хэштеги.
     Идеи — адаптация **формата**, а не копия чужого ролика.
6. Кратко перескажи пользователю главное со ссылкой на `analysis.md`.

## Правила

- Держи объёмы умеренными (настройки по умолчанию), не увеличивай частоту запусков без
  просьбы пользователя: аккаунт может получить ограничения.
- Не скачивай чужие видео и не перезаливай их.
- Отмечай, что сгенерированный контент — ИИ (метка AI-generated в TikTok).

## Разработка

- `pytest` — все тесты; сквозной тест `tests/test_collector_e2e.py` работает с локальным
  макетом сайта. Без установленных браузеров Playwright: `TRENDBOT_CHROMIUM_PATH=<путь к chromium>`.
- Парсер `trendbot/parse.py` ищет ролики в любом JSON по форме объекта; при изменениях
  сайта сначала сохрани пример ответа в тестовую фикстуру.
