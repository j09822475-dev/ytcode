# Поиск и разбор трендов TikTok

Работай из корня репозитория. Отвечай пользователю по-русски.

## 1. Подготовка

- Нет `trendbot.toml` → скопируй `trendbot.example.toml` в `trendbot.toml` и спроси у
  пользователя нишу, язык, 2–5 ключевых слов для поиска и 2–5 хэштегов ниши. Впиши.
- Нет папки `data/browser-profile` или пользователь ещё не входил → запусти `trendbot login`
  и попроси пользователя войти в TikTok в открывшемся окне браузера. Команда сама
  завершится после входа. Логин, пароль и коды не спрашивай и не вводи сам.
- `trendbot` не найден → `pip install -e .` в активированном venv (см. `docs/SETUP.md`).

## 2. Сбор

Запусти `trendbot run` (несколько минут; окно браузера будет листать TikTok — предупреди
пользователя, чтобы не закрывал его). Если долго нет вывода или в выводе
«⚠ TikTok показал проверку» — попроси пройти капчу в окне браузера. Не обходи её.

Если собрано 0 роликов: проверь, что вход выполнен (попроси пользователя взглянуть на окно);
если вход есть — вероятно, сайт изменился, иди в раздел «Когда TikTok поменял сайт» в
`CLAUDE.md`.

## 3. Чтение отчёта

- Открой самую новую папку `data/reports/*/`: `report.md`, при необходимости `trends.json`.
- **Посмотри кадры** `frames/<id>/*.png` каждого ролика из топа (Read по картинкам) —
  выводы о формате делай по кадрам, а не только по описаниям.
- Учитывай: «прирост роликов/час» появляется только после второго и следующих запусков.
  Если запуск первый — скажи, что свежесть трендов оценена по возрасту роликов.

## 4. Разбор → `analysis.md` в той же папке

1. **Тренды (3–5)** — звук, формат или тема. Для каждого: примеры (ссылки из отчёта),
   почему работает, насколько свежий (возраст роликов, прирост), подходит ли нише, риск
   «уже прошёл».
2. **Общее у лучших роликов**: хук в первые 1–2 секунды, текст на экране (есть ли, какой),
   длина, темп монтажа, лицо в кадре или нет, съёмка/скринкаст/слайды, призыв к действию.
3. **5 идей роликов** для канала пользователя. Для каждой: на какой тренд опирается, хук
   (первая фраза и первый кадр), сцены по секундам, текст на экране, звук, описание,
   3–6 хэштегов. Это адаптация формата под нишу, не пересъёмка чужого ролика.
   Пометь, что при публикации нужна метка AI-generated, если ролик сделан ИИ.
4. **Что проверить в следующий раз** — какие звуки/хэштеги отслеживать, какие слова
   добавить в `keywords`.

## 5. Ответ пользователю

5–10 строк: главные 2–3 тренда, лучшая идея, путь к `analysis.md`. Не пересказывай весь
отчёт. Предложи повторить сбор через 8–24 часа, чтобы увидеть рост.
