# trendbot — поиск трендов TikTok через браузер

Эксперимент: Claude сам смотрит TikTok на вашем компьютере, находит тренды и предлагает
похожие ролики для вашего канала. **Без сторонних API** — только обычный браузер.

## Как это работает

```
 ваш компьютер
 ┌──────────────────────────────────────────────────────────────────────┐
 │ Claude Code ──► trendbot collect ──► Chromium (ваш вход в TikTok)    │
 │                     │                  листает ленту, поиск, хэштеги │
 │                     │◄── JSON, который сайт сам загружает в браузер   │
 │                     ▼                                                │
 │               data/trendbot.sqlite  (снимки статистики по времени)   │
 │                     ▼                                                │
 │ trendbot report --frames ──► отчёт .md + кадры лучших роликов (.png) │
 │                     ▼                                                │
 │ Claude читает отчёт, смотрит кадры ──► разбор трендов и идеи роликов │
 └──────────────────────────────────────────────────────────────────────┘
```

1. **Сбор (Playwright).** Открывается окно Chromium с отдельным профилем. Сборщик ведёт
   себя как зритель: смотрит ролики ленты «Для вас» по несколько секунд, открывает поиск
   по ключевым словам ниши, страницы хэштегов и самых частых звуков. Он **пассивно читает**
   данные, которые сайт и так присылает в браузер: просмотры, лайки, комментарии, репосты,
   сохранения, дату публикации, звук, хэштеги, число подписчиков автора. Это точнее и
   надёжнее, чем распознавать скриншоты.
2. **Статистика (локально).** Для каждого свежего ролика считаются просмотры в час,
   вовлечённость и «выстрел» (просмотры / подписчики автора). Звуки и хэштеги
   ранжируются по тому, сколько быстрорастущих роликов их используют и как растёт число
   роликов с ними между запусками.
3. **Кадры.** У лучших роликов снимаются скриншоты плеера в заданные секунды (хук,
   середина). Видео не скачиваются.
4. **Анализ — Claude.** Claude Code читает отчёт и смотрит кадры: какие форматы, хуки,
   монтаж и темы работают — и пишет идеи и сценарии под вашу нишу. Порядок описан в
   [`CLAUDE.md`](CLAUDE.md).

## Установка (на вашем компьютере)

```bash
git clone <этот репозиторий> && cd ytcode
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
playwright install chromium        # или browser_channel = "chrome" в конфиге
cp trendbot.example.toml trendbot.toml   # и впишите свою нишу, ключевые слова, хэштеги
```

## Использование

```bash
trendbot login            # один раз: войти в TikTok в открывшемся окне
trendbot run              # сбор + отчёт с кадрами  → data/reports/<дата>/report.md
# или по шагам:
trendbot collect --feed 30
trendbot report --frames
```

Проще всего — открыть папку в Claude Code и написать: «найди тренды». Claude сам
запустит сбор, прочитает отчёт и сделает разбор.

Запускайте сбор 1–3 раза в день: колонка «прирост роликов/час» считается между запусками —
именно она показывает, что тренд **набирает** силу, а не уже прошёл.

## Важно

- **Правила TikTok** запрещают автоматизированный сбор данных. Риск — ограничения для
  аккаунта, под которым работает браузер. Поэтому: отдельный аккаунт для эксперимента,
  умеренные объёмы (по умолчанию ~40 роликов ленты за запуск), паузы как у человека.
- Капчи и проверки входа **не обходятся**: сборщик останавливается и ждёт, пока вы
  пройдёте их в окне браузера.
- Сайт TikTok меняется. Парсер не привязан к конкретным адресам — он ищет в любом ответе
  всё, что похоже на ролик, — но если данные перестанут собираться, пишите: поправлю.

## Тесты

```bash
pytest
```

Сквозной тест поднимает локальный макет сайта и гоняет настоящий Chromium: ленту,
поиск, хэштеги, звуки и снятие кадров. Если браузер Playwright не установлен, путь к
Chromium можно задать через `TRENDBOT_CHROMIUM_PATH`.
